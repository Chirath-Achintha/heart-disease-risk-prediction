# Heart Disease Risk Prediction Using Machine Learning

## 📌 Project Overview

This project focuses on predicting the risk of cardiovascular disease using machine learning techniques.

The aim is to analyze patient health and lifestyle information and build machine learning models that can predict whether a person is at risk of cardiovascular disease.

## 🎯 Objectives

- Analyze cardiovascular disease data
- Perform data preprocessing and exploratory data analysis
- Identify important factors related to cardiovascular disease
- Train machine learning classification models
- Evaluate and compare model performance
- Predict cardiovascular disease risk

## 📊 Dataset

We use the **Cardiovascular Disease Dataset** from Kaggle.

- **Source:** Kaggle
- **Records:** 70,000
- **Input features:** 11
- **Target:** Cardiovascular disease

### Main Features

- Age
- Gender
- Height
- Weight
- Systolic blood pressure
- Diastolic blood pressure
- Cholesterol
- Glucose
- Smoking
- Alcohol consumption
- Physical activity

### Target Variable

- `cardio = 0` → No cardiovascular disease
- `cardio = 1` → Cardiovascular disease
